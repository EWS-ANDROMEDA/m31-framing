# m31-framing
A serial framing library for transmission over unreliable connection, integrated with it an LUT-based CRC-16 [implementation](https://docs.robotis.com/docs/dxl/protocol/crc/).

This is a library written on top of [cobs-c](https://github.com/cmcqueen/cobs-c) used to better frame our Clearpath Robotics [Proton](https://github.com/clearpathrobotics/proton)-based serial communications, but can be used to frame arbitrary payload.
